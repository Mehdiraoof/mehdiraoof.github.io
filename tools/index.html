Free Chrome extensions

SEO tools I built for my own work

When a task kept eating my day, I wrote a small Chrome extension for it. These are the ones I use myself. They are free, they run in your browser, and you don't need an account.

The extensions

One live, two on the bench.

Live · v1.2 Chrome Web Store

HTTP Status Checker for SEOs

Check the status codes of a whole URL list in one go, then export each group as a CSV.

  • Paste URLs one per line, or upload a CSV or XLSX file with a column named URL.
  • Results are grouped by status code, so 404s and errors stand out at once.
  • Download any status group as its own CSV, ready to hand over as a fix list.
  • Runs in your browser. Your URL lists and results are not sent to any outside server.

In development Google SERPs

Page Pulse

See which SERP features Google shows for a keyword, and which words a results page repeats most.

  • Spots close to 30 SERP features, including AI Overviews, People Also Ask, featured snippets, local packs and Top Stories.
  • Batch mode: paste a keyword list and it checks each Google results page in turn.
  • Keyword frequency for the page you're on, with your own minimum repeat count.
In development Any web page

Advanced Search for SEOs

Ctrl+F for a whole list. Paste keywords, URLs or phrases and highlight every match on the page.

  • Check keyword use, competitor mentions or required wording on a page in seconds.
  • Next up: compare your list against a CSV, XLSX or DOCX file.
Why build them

Small tools, real hours saved.

Most of my work is on large sites with thousands of URLs. Checking status codes after a migration or reviewing SERP features for a keyword set by hand takes hours. These extensions do the boring part, so I can spend that time on the decisions.
