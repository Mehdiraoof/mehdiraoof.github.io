PulseO Privacy Policy

Last updated: 17 October 2026

Who we are

PulseO is a free, open source tool made by Mehdi Raoof (Istanbul). Contact: Mehdiraoof744@gmail.com. "Operator" means the person who sets up and runs PulseO for a site.

What data PulseO accesses

When you sign in with Google or grant access, PulseO requests:

  • Google Search Console, read only: search performance data for the properties you choose (queries, pages, clicks, impressions, CTR, average position, device, country, dates).
  • Google Sheets and Drive: to create and update the report spreadsheets you set up for PulseO.

It does not read your Gmail, contacts, or any files it was not set up to use.

How the data is used

Only to build the sheets, reports, alarms and decks you asked for. Not for ads, not for profiling, and it is not sold.

Where the data is stored

In your own Google Sheets. Credentials and settings are stored by the operator as encrypted GitHub Actions secrets or in a local token file on the operator's computer. PulseO has no server or database of its own.

Sharing

Data is shared only with:

  • Google, to read and write your data.
  • GitHub, which runs the schedule.
  • The email recipients the operator chooses, who receive the decks.
  • Only if the operator turns on the optional AI summary: Anthropic's API, which receives aggregated numbers plus top queries and top pages to write a short summary, never credentials, IDs or full tables.

Google user data is never used to train AI models. When I run PulseO for a client, I access that client's data only to produce their reports.

Google API Services, Limited Use

PulseO's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays in your sheets until you delete them. To stop PulseO, remove its access at https://myaccount.google.com/permissions and delete the sheets and secrets. Questions or deletion requests: email me.

Security

Read-only Search Console access, secrets kept out of logs, and site names and IDs hidden from public logs.

Children

PulseO is not meant for children under 16.

Changes

I'll update this page and its date when anything changes.
